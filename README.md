### Scripto
- a simple tool that handles scripts execution built using C++ & Qt

## Build Requirements
- Qt v6 (MSVC)
- Visual Studio (with Qt VS Tools installed)

## How to Use
- after installing the app it will be added to autostart  list automatically
- run the app using the start menu
- no window will appear but the app will be up and running in the background and you will be able to use it through keyboard shortcuts

## Keyboard Shortcuts
- ```Ctrl + Shift + R``` will open the main window of the app, you can then enter the name of the script and Press Enter to run the script, this will launch a new terminal session (this option is not editable yet) 
- ```Ctrl + N``` while the main window is active will open a new script dialog to add new script
- ```Ctrl + R``` while the main window is active will open remove script window to remove scripts
